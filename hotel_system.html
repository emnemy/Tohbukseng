Restore จากไฟล์ Backup
ขั้นตอนการ Restore
1. เปิด Google Drive → โฟลเดอร์ HotelBackups → ดาวน์โหลดไฟล์ hotel_backup_YYYY-MM-DD.json ที่ต้องการ
2. คลิก "เลือกไฟล์ Backup" ด้านล่าง → เลือกไฟล์ที่ดาวน์โหลดมา
3. ตรวจสอบข้อมูลใน Preview ว่าถูกต้อง
4. กด "Restore ข้อมูล" — ระบบจะแทนที่ข้อมูลปัจจุบันทันที
⚠️ คำเตือน: การ Restore จะลบข้อมูลปัจจุบันทั้งหมดและแทนที่ด้วยข้อมูลในไฟล์ backup — ไม่สามารถย้อนกลับได้

Archive ข้อมูลเก่า
วิธีการทำงาน
1. เลือกปีที่ต้องการ Archive เช่น 2568
2. ระบบจะย้าย booking ที่ checkOut ก่อน 1 ม.ค. ของปีถัดไปไปเก็บใน Sheet ใหม่ชื่อ bookings_2568
3. Sheet หลัก bookings จะเหลือแค่ข้อมูลที่ยังไม่ถูก Archive
4. ดูข้อมูลเก่าได้โดยเปิด Google Sheets และดูที่ tab bookings_2568
⚠️ แนะนำ: Backup ข้อมูลก่อนทำ Archive ทุกครั้ง — Archive แล้วย้อนกลับไม่ได้ผ่าน UI
